# 如何约束大模型的输出格式和规则？

## 原题原文

> 模型输出结果如何控制规则？

## 答案

### 面试直答

约束大模型输出应采用“结构化生成 + Schema 校验 + 业务规则 + 自动修复/重试 + 安全降级”，不能只在 Prompt 中说“必须输出 JSON”。高风险字段必须由代码验证。

### 一、约束层次

优先使用 Function Calling 或 JSON Schema；限制枚举、类型、范围和必填字段；解析后做跨字段业务校验。失败时把具体错误反馈给模型进行一次有限修复，仍失败则降级或人工处理。

> **核心小结：** 模型负责生成候选，代码决定候选是否可被系统接受。

### 二、工程注意

不要用脆弱正则修补任意 JSON；保存原始输出和校验错误；幂等写操作在校验后执行；防止 Prompt Injection 把系统规则写进数据字段。评估格式合法率、首次成功率、修复成功率和语义正确率。

> **核心小结：** 格式合法只是第一关，业务语义、权限和副作用还需独立验证。
