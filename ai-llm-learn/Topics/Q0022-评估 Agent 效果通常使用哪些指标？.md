# 评估 Agent 效果通常使用哪些指标？

## 原题原文

> "评估Agent效果你们用什么指标？

## 答案

### 面试直答

评估 Agent 不能只看最终答案准确率。我会从**结果、过程、效率、可靠性和安全性**五层建立指标，并按任务类型设权重。最终任务成功是北极星指标，过程指标用于解释为什么成功或失败。

### 一、指标体系

| 层级 | 典型指标 |
|---|---|
| 结果 | Task Success、正确性、完整性、用户目标达成率 |
| 过程 | 计划合理率、工具选择准确率、参数正确率、无效步骤率 |
| 效率 | 总延迟、首 Token、P95、Token、工具次数、成本 |
| 可靠性 | 超时率、重试率、循环率、恢复成功率、一致性 |
| 安全 | 越权率、敏感信息泄露、危险动作拦截率 |

开放任务可使用规则、执行结果和 LLM Judge 组合评分；涉及确定答案时优先使用可执行验证，例如代码测试、SQL 执行和标准证据。

> **核心小结：** 结果指标决定有没有用，过程指标决定应该优化模型、规划、检索还是工具。

### 二、离线与线上闭环

离线评测集覆盖正常、边界、工具失败、歧义和对抗样本；固定版本后做回归。线上监控真实成功率、用户改写/重试、人工接管、P95 和成本，并抽样人工复核。线上失败经脱敏后进入离线集，形成闭环。

> **核心小结：** 离线保证可重复比较，线上验证真实分布，两者必须互相补充。

### 三、注意事项

- LLM Judge 与被测模型尽量分离，并用人工集校准偏差。
- 同时报告均值和长尾，Agent 生产问题常出在 P95/P99。
- 多轮验证能提高实验准确率，但要单独评估单轮直出和低延迟形态。
- 指标提升必须配显著性、样本量和成本变化，避免只挑成功案例。

> **核心小结：** 评估必须同时约束质量、延迟、成本和风险，不能用更多轮调用换准确率后只报告准确率。

### 常见追问

- **没有标准答案怎么办？** 定义完成条件和评分 Rubric，结合过程证据、人工评审与多 Judge 一致性。
- **最重要的指标是什么？** 与业务目标一致的端到端成功率，但必须配套过程和效率指标。
