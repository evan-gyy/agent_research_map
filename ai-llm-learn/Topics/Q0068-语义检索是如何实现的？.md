# 语义检索是如何实现的？

## 原题原文

> 语义检索是如何实现的？

## 答案

### 面试直答

语义检索将 Query 和文档编码成同一向量空间，用余弦相似度或点积查找语义相近内容。工程流程包括离线分块与 Embedding、ANN 索引，在线 Query 编码、权限过滤、Top-K 召回、重排和证据返回。

### 一、流程

$$sim(q,d)=\frac{q\cdot d}{\|q\|\|d\|}$$

向量库用 HNSW、IVF 等近似最近邻算法加速，不逐条全量计算。Metadata 过滤应在检索阶段生效，防止越权 Chunk 被召回。

> **核心小结：** 语义检索是表示学习加近似最近邻，不等于直接让大模型阅读全库。

### 二、局限

对编号、人名和精确词可能不如 BM25；Embedding 也会受领域和切分影响。因此常用混合召回加 Reranker，并用 Recall@K、MRR 和延迟评估。

> **核心小结：** 向量召回覆盖语义，关键词和重排补足精确性与排序。
