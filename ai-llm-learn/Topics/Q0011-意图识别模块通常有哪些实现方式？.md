# 意图识别模块通常有哪些实现方式？

## 原题原文

> 意图识别模块通常有哪些实现方式？

## 答案

### 面试直答

意图识别可分为规则、传统分类器、小模型/Embedding、大模型和分层混合路由。选型取决于类别稳定性、样本量、延迟、可解释性和长尾开放性；生产中常用“规则兜底 + 轻量分类 + 大模型处理模糊样本”。

### 一、方式对比

| 方式 | 优点 | 适用 |
|---|---|---|
| 规则/关键词 | 快、可控 | 高精度固定意图 |
| 监督分类 | 稳定低成本 | 标签固定且有数据 |
| Embedding KNN | 新类扩展快 | 示例驱动路由 |
| 大模型 | 语义与长尾强 | 多意图、少样本 |
| 分层路由 | 平衡成本效果 | 大规模生产系统 |

> **核心小结：** 高频确定意图前置到轻量方法，模糊长尾再升级大模型。

### 二、工程设计

支持多标签和 unknown；输出意图、置信度和证据；低置信澄清而非强分。按时间和用户表达切分评测，关注 Macro-F1、路由成功率、拒识率、延迟和成本。

> **核心小结：** 意图识别必须允许“不确定”，否则新增场景会被错误塞进旧标签。
