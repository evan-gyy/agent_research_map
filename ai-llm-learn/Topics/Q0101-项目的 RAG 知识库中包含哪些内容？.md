# 项目的 RAG 知识库中包含哪些内容？

## 原题原文

> 知识库里加了什么内容？

## 答案

### 面试直答

这是一道项目事实题，不能凭空编造知识库内容。回答应按“知识来源—数据类型—更新频率—权限—规模—使用场景”说明，并只引用项目真实资料。若以旅行 Agent 为例，可以描述公开可确认的旅行技能与业务知识范围，但具体文档数量和线上覆盖率需要真实台账。

### 一、回答模板

知识库可以按以下维度介绍：

- 业务知识：酒店、景点、目的地攻略、产品规则等。
- 结构化数据：实体属性、地理位置、标签和时间字段。
- 非结构化文档：FAQ、运营文档、制度和说明。
- 元数据：来源、版本、更新时间、权限和语言。
- 负面/评测样本：历史失败问题、标准证据和参考答案。

> **核心小结：** 这道题要确认你是否真正理解数据，而不是只给出“有很多文档”的空泛回答。

### 二、工程治理

说明文档如何解析切分、如何增量更新、权限如何下沉到 Chunk、过期内容如何淘汰，以及哪些数据不能进入知识库。最好给出一个真实 Query 如何命中具体来源的例子。

> **核心小结：** 知识库的价值取决于可追踪、可更新和可授权，而不只是向量数量。

### 三、数字边界

如果没有真实统计，应说“当前代码能确认数据类型和链路，但规模需要从索引台账补充”，不要编造一万篇、命中率或提升百分点。

> **核心小结：** 项目题宁可明确缺少数据，也不要用虚构指标换取表面完整。
